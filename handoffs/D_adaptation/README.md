# D 漂移检测与重训实验交接

实验使用课程 CSV、C 的固定日型距离和 Stage 1 交接的模型。模拟覆盖 2015-01-01 至 2026-10-31，共 4,322 个 AEST 市场日。需求适应实验使用 MLP，电价适应实验使用 HistGradientBoostingClassifier。四个候选冻结模型的完整结果继续读取 `outputs/frozen_backtest/`。

## 复现

在仓库根目录使用项目的 Python 3.11 环境。模型和依赖版本见 `requirements.txt`。先确认课程 CSV 在 `data/nem_weather_halfhourly_2010_2026.csv`。以下三条命令默认将结果放入 `outputs/adaptation/`，也可对三条指定相同的 `--output`。

```sh
python -m experiments.backtest_adaptation
python -m experiments.adaptation_results
python -m experiments.verify_adaptation
```

提交代码仓库的现有产物包含初始 MLP 权重、初始价格分类权重、日型距离表和冻结对照预测，运行上述命令会使用这些文件。要重新生成冻结对照和价格权重，可参考 `outputs/frozen_backtest/README.md`。其中的初始 MLP 可用 `python -m experiments.train_frozen_demand` 重建。

## 实验规则

| 项目 | 实现 |
| --- | --- |
| 输入统计量 | C 的 `nearest_center_distance`。当天最后一个半小时结束后读入。PCA 和聚类参考以 2010–2013 年拟合结果固定。 |
| 误差统计量 | 当前部署版本当天的需求 MAPE 或电价误分类比例，单位均为百分数。 |
| 校准与报警 | 2014 年内完整的 28 日窗口，按窗口末日的澳洲季节分组，分别取第 95 百分位。用 2014 年末 27 天填初始窗口。第 7 个连续超阈值的市场日报警一次。回落至阈值或以下后可重新报警。 |
| 冻结监控 | 在冻结模型上继续运行两个检测器，用于比较报警日期与退化。 |
| 定期更新 | 2016、2018、2020、2022、2024、2026 年 1 月 1 日启用新模型。 |
| 报警更新 | 任一检测器报警且仍有预算时更新。同日双报警合并为一次。新版本启用后，误差窗口从空开始，输入窗口继续累计。 |
| 训练窗口 | 生效日前三年到生效前一天的市场日作为训练样本。窗口开头的滞后特征可用更早七天的已观测历史。沿用原算法、超参数和特征，重新拟合模型和预处理。 |
| 预算与时间 | 每个任务、每条策略最多更新六次。第 D 天结束才知道该日误差，当天作出的更新决定从 D+1 的预测起生效。 |
| 选型与复核 | 按 2015–2024 合并成绩选择。需求以 MAPE 最低为优，电价以 balanced accuracy 最高为优，分数相同时选更新较少者。2025–2026 年 10 月用于复核，延续原模拟中的模型状态与已用预算。 |

月图的区间用于需求 MAPE 和电价 accuracy，分别按独立半小时的正态近似和整天区块 bootstrap（1,000 次）计算。另做配对的 14 天循环移动区块 bootstrap（2,000 次），估计两种策略在相同日期上的主要指标差。电价 balanced accuracy 在每次重抽样后用合计的正确分类数与真实类别数重算。正增益表示候选策略更好。

## 组员解读时的核对点

- 输入报警和误差报警监测的是不同现象。核对同日两项滚动统计是否同时超阈值，也看报警之后的误差。对归一化曲线的 PCA 距离主要描述日内形状变化，可能弱化用电水平变化，也不直接测量价格条件关系。
- 一个季节仅用 2014 年校准。相邻 28 天窗口高度重叠，因此第 95 百分位不能直接解释为独立的 5% 日误报率。较高的超阈值天数和较少的报警次数可以同时出现，因为连续偏高只报一次。
- 月度区间估计相同月份条件下的期望表现。整天抽样保留日内依赖，但持续数日的天气和工作日结构会造成跨天依赖。用整周做月内重抽样时，一个月只有四五个完整周。14 天配对区间用于比较策略，仍无法消除多年分布变化带来的不确定性。留出期的比较可用于验证走势是否延续。
- 市场事件日期只用于事后定位，从未作为模型特征、阈值校准或训练输入。AEMO 确认五分钟结算于 2021-10-01 生效，现货市场于 2022-06-15 暂停。前后窗口只能描述时间上的变化，且 28 日滚动有延时，两种检测器也不能自行识别概念漂移。[五分钟结算](https://www.aemo.com.au/initiatives/major-programs/past-major-programs/five-minute-settlement/5ms-program-management/5ms-commencement) · [2022 年市场暂停报告](https://www.aemo.com.au/-/media/files/electricity/nem/market_notices_and_events/market_event_reports/2022/nem-market-suspension-and-operational-challenges-in-june-2022.pdf)

以下是找结果时可以对照的记录。

- `selection.csv` 两项均选择定期，其选择期内使用五次更新。整段历史内定期和报警都使用六次。两项任务的报警策略在 **2016-03-04** 生效第六个版本，之后发生的报警有 34 次（需求）和 38 次（电价）因预算用尽而没有更新。
- `paired_gains.csv` 在 2025–2026.10，定期相对报警将需求 MAPE 降低 5.72 个百分点，配对 95% 区间为 [5.00, 6.46]。电价 balanced accuracy 提高 22.00 个百分点，区间为 [20.54, 23.43]。定期电价模型同期比昨天基线高 3.99 个百分点，区间 [2.91, 5.07]，在全期则低 1.25 个百分点，区间 [-2.19, -0.29]。
- `detector_summary.csv` 冻结线首次误差报警为 2015-01-07，首次输入报警是 2015-07-27。输入统计超阈值但误差统计未超阈值的市场日分别有 643 天（需求）和 451 天（电价）。留出期连续 669 天，两项冻结误差统计和输入统计始终超阈值，因此此段没有新报警。这是长期超阈值和事件式报警两者的区别。
- `monthly_metrics.csv` 定期模型的月度区间平均宽度，需求 MAPE 为 0.44（半小时独立）与 1.43（整天 bootstrap）个百分点，电价 accuracy 为 4.45 与 10.60 个百分点。
- `market_event_windows.csv` 五分钟结算开始前后各 28 天，冻结电价 accuracy 为 74.33% 和 60.57%，昨天基线为 74.40% 和 74.85%。冻结误差检测在 2021-10-10 报警。2022-06-15 市场暂停当天，冻结电价误差的 28 日均值为 49.85%，超过阈值 25.30%，但已处在先前报警后持续超阈值的状态，未产生新报警。前后窗口和信号仅提供解释线索。
- `simulation.json` 本次在 Linux 下运行，标签、时间戳和两条基线与旧回测逐条一致。冻结需求预测最大差约 1.1×10⁻¹¹ MW。冻结价格预测有 4 个时段不同，占 207,456 个时段的约 0.0019%。诊断发现这四行对 `season_cos` 的一个浮点末位差异敏感。三条策略使用本次同一环境的冻结预测作为起点。
- `retraining.csv` 保留了 MLP 迭代上限警告，定期策略五次、报警策略两次。历史研究保留模型原始输出。定期需求模型所有历史预测均在 0–20,000 MW 内，报警需求模型有 108 个时段超出最终提交的有效范围。

供 E 接手时核对，两项定期策略在历史模拟中最后一次更新的训练样本为 **2023-01-01 至 2025-12-31**，生效日为 **2026-01-01**。记录的是 Stage 2 复核所用训练窗口，最终提交的训练截止日和窗口由 E 依据 Stage 3 规则选择。
